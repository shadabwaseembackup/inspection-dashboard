How things are counted

• Done: Date of Visit or Lineman filled (FP SP also: status not Pending; DT also: any check column filled).
• Deficiency: a check marked Not OK / No / खराब, pillar earthing = 0, HRC base/fuse needed > 0, substation not locked, plus any non-blank team remark (other than OK/No/Nil).
• "No WTI" is treated as not available, not a failure.
• Remark status: "Rectified" when the rectified column says OK/Yes; "Open" when blank/No; otherwise "unclear".
• Duplicate FP SP rows are merged on DT code + feeder + pole number.
• DT rows with no asset ID are ignored.
